# aditivetensornetwork

This project uses a Python virtual environment created in `.venv`.

Quick start (PowerShell):

```powershell
Set-Location -Path "D:\aditivetensornetwork"
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Quick start (cmd):

```cmd
D:\aditivetensornetwork\.venv\Scripts\activate.bat
pip install -r requirements.txt
```

If `python -m venv .venv` failed, ensure Python is installed and on PATH.
